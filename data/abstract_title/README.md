These data include patent title and abstract, and they come from ‘g_patent’ and ‘g_patent_abstract’ (https://data.uspto.gov/bulkdata/datasets -> PatentsView Granted Patent Disambiguated Data). This folder includes 10 different zip files. For ease of download and ease of importing, files are divided by patent number. File “abstract_title_non_utility.tsv.zip” includes all non-utility patents. File “abstract_title_5m.tsv.zip” includes all patents issued beginning January 1976 through patent number 5,000,000. File “abstract_title_6m.tsv.zip” includes all patents between patent number 5,000,001 and patent number 6,000,000. Etc, etc. Data are updated through December 2025. These files include the following columns:

| Variable    | Description                               |
| ----------- | ----------------------------------------- |
| patnum      | Patent number                             |
| title       | Patent title                              |
| abstract    | Patent abstract                           |
